# 大肥鱼的声音

让 QQ 机器人带情绪地发语音（现在是芙宁娜人格 + 芙宁娜音色），并能清唱点歌：芙宁娜本人唱，或者请特邀嘉宾大肥鱼唱。

## 依赖

本机 `~/dafeiyu-tools` 里的两个服务（插件会按需自动拉起，闲置后自动退出）：

- 说话服务 `breeze_tts_server.py`（127.0.0.1:9880，Breeze TTS 2）
- 唱歌服务 `sing_server.py`（127.0.0.1:9881）：芙宁娜用社区芙宁娜 RVC 模型（`rvc_worker.py`），大肥鱼用 Seed-VC；人声分离用 Roformer 分人声 + 去和声（`sep_worker.py`）

手动启停：`bash ~/dafeiyu-tools/dafeiyu-voice.sh start|stop|status`

## 语音回复

- 大模型回复开头的【开心】【傲娇】【嘴硬】【委屈】【害羞】【惊讶】【平静】决定语气，标签一定会被去掉。
- 对方消息含“语音 / 说给我听 / 用声音说 / 发语音”时必发语音；否则按概率随机发。
- 超过 60 字、每群每分钟超过 3 条时发文字。颜文字、（动作）、网址不念。

## 唱歌

- `/唱 歌名 [歌手] [起点如 1:47] [芙宁娜|大肥鱼]`、`/歌单`、`/唱歌 状态`
- 谁来唱：点歌时先问对方“想听本女士亲自献唱，还是请特邀嘉宾大肥鱼登台？”，只认点歌的人本人回答；点歌时已经说了就不问，60 秒没回答用默认歌手（`/唱歌 音色` 改，默认大肥鱼）。配置 `ask_singer` 关掉就不问。大肥鱼唱时开唱前先发 `guest_start_tip`，芙宁娜唱时发 `sing_start_tip`。
- 自然语言点歌：大模型调用 `sing_song` 工具（参数 singer 填谁唱，没填时工具让大模型先问），做好后自动发清唱。30 秒片段：芙宁娜不到 1 分钟，大肥鱼约 3.5 分钟。
- 分离：先分出人声，再用 karaoke 模型去掉和声（2026-11-10 试听：泡沫的电音没了）；去和声后主唱几乎没声音（模型把主唱当成了和声，如唯一 0:15）就自动退回全部人声。
- 点错歌名：歌单里有只差一两个字的歌时，先问“你是想听《X》吗”，回「是」就唱那首。
- 学新歌前确认：先只搜索不下载，告诉你找到的版本（来源、歌手、时长），回「是」才下载，下的就是你确认的那首。
- 原唱太高/太低：默认不拒绝，唱歌服务把它升降调拉到她的音域再唱，开唱前先发一句“可能唱得不太好”（文字在配置 stretch_tip_high / stretch_tip_low 里改）。想恢复成直接拒绝，启动唱歌服务时设环境变量 DAFEIYU_SING_STRETCH=0。
- 学完唱不了（没人声/太短；关掉硬唱时还有太高/太低）：自动删掉下载的音频和分离缓存并拉黑，免得占地方、重复下载。自己放进库的歌不会被删。
- 想学清单：点到歌曲库里没有的歌时，记进 `歌曲库/想学的歌.txt`（`/学歌 想学` 查看）。带歌手名发 `/唱 歌名 歌手` 让她学，或照着清单去下载。
- 学歌（默认关）：`musicdl` 走本机 go-music-dl 的 12 个源（网易云、QQ、酷狗、酷我、咪咕、千千、汽水、JOOX、Apple Music、B站、5sing、Jamendo）；`bili` 走 B 站。B 站经常拒绝脚本访问（412），被拒后暂停一小时。各平台要在 go-music-dl 里登录/Cookie，VIP 歌曲要会员。
- 自己加歌：把下载的 .ncm / mp3 / flac 放进 `歌曲库/待导入/`，会自动解密、改名入库。
- 歌曲库 `~/dafeiyu-tools/歌曲库`：`清唱/`、`原曲/` 里放“歌手-歌名.m4a”，`片段.txt`、`白名单.txt`、`黑名单.txt`。

## 管理员指令

- `/语音 开`、`/语音 关`、`/语音 概率 0.5`、`/语音 状态`（只影响当前群）
- `/声音 开`、`/声音 关`、`/声音 状态`（两个服务）
- `/学歌 歌名 歌手 起点`：学一首歌的指定版本，如 `/学歌 雨爱(司风版) 时年先生 0:15`（最后一段是歌手、带时间就是起点；谁能用看 /学歌 所有人|仅管理员|关）。库里已有就直接唱；只有别人唱的同名歌时先问“是不是这首”；没有就搜到版本、问“是这首吗”再下载。歌名里的版本说明（司风版、Live…）会保留，不会拿原版顶替。
- `/唱歌 片段 歌名 1:47`：改这首歌默认唱哪一段（写进 歌曲库/片段.txt）；`/唱歌 片段 歌名 自动` 改回自动挑：按歌词找副歌、挑和声少高音少的那遍（歌词存在 歌曲库/歌词/；找不到歌词时挑人声最响的一段）；`/唱歌 片段 歌名` 看现在从哪唱。只想临时换一段就直接 `/唱 歌名 1:47`。
- `/唱歌 清缓存 歌名`：只清这一首做好的清唱（芙宁娜、大肥鱼的都清），下次点重新唱；不带歌名就清全部。
- `/唱歌 音色`：看默认歌手（没选谁唱时用）；`/唱歌 音色 芙宁娜` / `/唱歌 音色 大肥鱼` 切换，马上生效。两个歌手的缓存分开存。雨爱音色 2026-11-10 已去掉。命令行：`dafeiyu-voice.sh voice furina|dafeiyu`
- `/声音 模型`：看说话用的模型；`/声音 模型 index` / `/声音 模型 breeze` 二选一切换（IndexTTS2 情绪更强烈，Breeze TTS 2 声音更好听；唱歌不受影响）
